# Дублёр — помощник для Telegram Business

Telegram называет эту роль «режимом секретаря». Дублёр — тот, кто
выходит на площадку вместо вас, и его не отличают от вас.

Бот подключается в **Настройки → Telegram для бизнеса → Автоматизация
чатов** и в личных чатах владельца делает четыре вещи.

| | Что | Коротко |
|---|---|---|
| 💬 | **Автоответы** | правила «слова → ответ», режим «отошёл», приветствие новым |
| 🛡 | **Антискам** | разбирает первые сообщения от незнакомых по очкам и объясняет решение |
| 🗑 | **След** | показывает, что собеседник удалил или переписал — с текстом и файлом |
| ⌨️ | **Команды** | 96 команд прямо в переписке: текст, игры, фото, профиль |

Всё управление — кнопками в личке бота. Один бот обслуживает сколько
угодно владельцев: у каждого свои правила, тексты, архив и статистика,
они не пересекаются.

## Чем отличается от похожих ботов

Это не список «у нас тоже есть» — это места, где сделано иначе.

**Антискам объясняет себя.** Обычный фильтр — список слов: слово
нашлось, сообщение удалено. Здесь каждый признак даёт очки, и в
карточке видно сумму: «6 из 3 — предложение работы +3, суммы и обещания
дохода +3». Ошибку такой системы можно понять и поправить порогом.

**Антискам знает контекст.** Коммерческие признаки проверяются только у
тех, с кем переписки ещё не было: вопрос «а на работу к вам можно?» от
давнего знакомого удалять нельзя. А вот исполняемый файл и просьба
прислать код из СМС ловятся всегда, в том числе у знакомых — именно так
выглядит взломанный аккаунт друга.

**Антискам не обманывается подменой букв.** «pa6oта» латинскими «a» и
«o» мимо списка слов проходит свободно; здесь текст сворачивается к
кириллице и проверяется дважды — и как написано, и как свёрнуто.

**Кнопка «это не спам».** Фильтр можно переубедить одним нажатием, а не
отключением целиком.

**Досье помнит поведение.** `.досье` показывает не только id и дату
регистрации, а то, что человек делал в переписке с вами: сколько
сообщений прислал, сколько потом **удалил**, сколько **переписал**,
сколько раз срабатывал антискам. Эти цифры бот собирает сам, поэтому их
неоткуда взять боту, который просто пересылает события.

**Команды на русском.** `.жирный`, `.досье`, `.глушь` — и короткие
`.ж`, `.кур`, `.мн`. Ни одного латинского имени: чтобы набрать `.bold`
посреди русской переписки, раскладку надо переключить дважды.

**Стилизация работает с кириллицей.** Юникод-шрифты (𝓼𝓬𝓻𝓲𝓹𝓽, ᴀʙᴄ, ⓐ)
существуют только для латиницы — это ограничение Unicode, его не
обойдёт никто. Поэтому для русского сделаны свои: разрядка, залго, лит
(«nucamb kak debul»), смена раскладки, транслит, случайный регистр,
увуфикация по-русски («пвивет»). Латинские стили честно помечены и
предупреждают, если дать им русский текст.

**В игры играет собеседник.** Партия объявляется командой, а ходы оба
делают обычными сообщениями — «5» в крестиках, «камень» в кнб. Кнопки
под сообщением в бизнес-чате работают ненадёжно, сообщение долетает
всегда. Крестики против бота играются минимаксом — обыграть нельзя.

**`.клон` умеет возвращаться.** Перед копированием чужого профиля свой
сохраняется в базу, включая аватар. `.вернись` — и всё как было.

**Бот объясняет своё молчание.** `.почему` в чате расскажет, что бот
решил по последнему сообщению и на каком основании.

## Что нужно

* **Telegram Premium** у владельца — без него раздела «Telegram для
  бизнеса» в настройках нет.
* **Business Mode у бота**: @BotFather → `/mybots` → бот → *Bot
  Settings* → *Business Mode* → *Enable*. Пока выключен, Telegram
  пишет «этот бот пока не поддерживает режим секретаря». Бот проверяет
  это при старте и предупреждает в логе.
* Python 3.10+.

## Установка

```bash
cd autochat
python -m venv .venv && .venv/Scripts/activate
pip install -r requirements.txt
cp .env.example .env        # впишите BOT_TOKEN
python main.py
```

`ADMIN_IDS` — ваш id, чтобы открыть `/admin` (статистика, баннер меню,
рассылка). `ALLOWED_IDS` в `.env` пустой — подключить бота может любой, кто его
найдёт (открытый режим). Впишите свой id, чтобы закрыть бота только для
себя.

## Права и что от них зависит

В «Автоматизации чатов» права выдаются по одному. Что выдали — то и
работает; чего нет, о том бот скажет прямо, а не промолчит.

| Право | Без него не будет |
|---|---|
| отвечать на сообщения | автоответов и результатов команд |
| удалять мои сообщения | подмены команды результатом — команда останется в чате |
| удалять любые сообщения | антискама с удалением, глухого режима, `.удали`, `.чисти` |
| менять имя / «о себе» / аватар | `.имя`, `.био`, `.аватар`, `.клон` |
| менять юзернейм | `.ник` |
| видеть подарки и звёзды | `.подарки`, `.звезды` |

## Админка бота

`ADMIN_IDS` в `.env` — id владельцев самого бота. Им доступна `/admin`;
у остальных команда не срабатывает, а пустой `ADMIN_IDS` означает, что
админки нет ни у кого.

**📊 Статистика по всему боту:** владельцев и активных подключений,
прирост за неделю, диалогов на обслуживании, правил и заготовок,
автоответов за сутки/неделю/всего, партий в играх, срабатываний
антискама, поймано удалённых и правок, размер архива. Отдельно —
самые активные владельцы.

**🖼 Баннер главного меню.** Пришлите фото — панель владельца будет
приходить картинкой с текстом под ней. Ограничение Telegram: подпись к
фото до 1024 символов, поэтому длинные экраны (справка, антискам) всё
равно придут текстом.

**📣 Рассылка.** Мастер из четырёх шагов и предпросмотр перед отправкой:

* **Текст** присылается **готовым сообщением** — с тем форматированием,
  которое вы расставили в своём Telegram. Бот забирает entities как
  есть, поэтому сохраняются жирный, курсив, подчёркнутый, зачёркнутый,
  спойлер, ссылки, моно, цитаты и премиум-эмодзи. Ручную разметку писать
  не нужно.
* **Вложение** — фото или стикер, в том числе премиум: бот отправляет
  стикер по `file_id`, анимация с эффектом сохраняется. Фото уходит
  одним сообщением с подписью, стикер — отдельным перед текстом
  (подписей у стикеров в Telegram нет).
* **Кнопки** — строками `Текст - ссылка`, две в ряд через `|`. Ссылки
  проверяются заранее: Telegram отклоняет неверную схему вместе со всей
  отправкой.
* **Кружок кнопки** — 🟢 🔵 🔴 или без него.

Отправка идёт в фоне: живой прогресс с оценкой остатка, кнопка
«Остановить», подсчёт доставленных, заблокировавших бота и ошибок.
Скорость ограничена (по умолчанию 20 сообщений в секунду), 429 от
Telegram переживается автоматически. История рассылок хранится.

### Две вещи, которых Telegram не умеет

Спрашивают часто, поэтому прямо:

* **Цвета инлайн-кнопок в Bot API нет.** У `InlineKeyboardButton` нет
  поля цвета — кнопку рисует клиент по своей теме. Всё, что выглядит
  как цветные кнопки у других ботов, — кружок в подписи. Именно это и
  делает выбор цвета.
* **Премиум-эмодзи внутрь кнопки не вставить:** текст кнопки — простая
  строка без entities. В тексте сообщения они работают, но отправить их
  бот сможет только если его юзернейм куплен на Fragment — это
  ограничение Telegram на `custom_emoji` для ботов.

## Команды

96 команд в семи разделах: **Слово** (33 стиля текста), **Кадры**
(6 анимаций), **Азарт** (19 игр и рандома), **Диалог** (16 команд по
переписке), **Личина** (8 профильных), **Картинка** (8 фильтров),
**Служба** (6 прочих).

Полный список с описаниями — `.помощь` в любом своём чате (приходит в
личку бота, в переписке не остаётся) или `/commands` в личке.

Как это выглядит: пишете в чате `.жирный привет` — бот убирает вашу
команду и отправляет от вашего имени **привет**. Со стороны так, будто
вы сразу написали жирным.

Немного примеров:

```
.досье              карточка собеседника и его поведение
.раскладка          Ghbdtn -> Привет, одной командой
.глушь              собеседник пишет в пустоту, текст приходит вам
.правило цена|прайс = скину вечером
.запомни прайс = стрижка 1500     .вставь прайс
.крестики бот       партия против минимакса
.шакал              (ответом на фото) пережать в мем
.почему             почему бот ответил или промолчал
```

Префикс меняется в панели: `.` `!` `,` `;` `~`.

## Антискам: очки

| Признак | Очки | Когда проверяется |
|---|---|---|
| выпрашивает код, пароль, «проголосуй» | 5 | всегда |
| исполняемый файл (.exe, .apk, .bat, …) | 5 | всегда |
| просит денег или реквизиты | 3 | всегда |
| работа, заработок, крипта, ставки | 3 | только новый диалог |
| суммы вида «от 5000 в день» | 3 | только новый диалог |
| ваше слово из списка | 4 | только новый диалог |
| ссылка, кнопки, зовёт в бота, розыгрыш, пишет бот | 2 | только новый диалог |
| срочность, простыня текста, форвард, контакт | 1 | только новый диалог |

Порог по умолчанию — 3. Диалог считается знакомым, если владелец в нём
писал сам, если пришло больше пяти сообщений или если чат помечен
доверенным.

## След: как это работает и чего ждать нельзя

Telegram присылает боту апдейт об удалении, в котором **только номера
сообщений** — ни текста, ни файлов. Поэтому бот складывает входящие в
свою базу при получении и достаёт оттуда, когда сообщение удаляют.
Отсюда ограничения:

* видно только то, что пришло **после** подключения бота;
* архив живёт ограниченный срок (по умолчанию 3 дня, меняется в панели);
* архивируются только **входящие** — свои сообщения бот не хранит;
* файл переотправляется по `file_id`; обычно он жив и после удаления,
  но самоуничтожающиеся фото так не достать — придёт карточка с
  пометкой, что файл недоступен;
* нужно, чтобы боту не отключили право читать сообщения.

Ловится всё, что приходит сообщением: текст, фото, видео, GIF,
голосовые, кружки, файлы, стикеры, геолокации, контакты.

## Чего здесь сознательно нет

* **Ставок на звёзды.** Звёзды — реальный платёжный актив; автоматически
  переводить их между людьми по итогу броска кубика бот не будет. Игры
  идут на очки, счёт хранится по каждому чату.
* **«Докса».** Настоящих персональных данных Telegram боту не отдаёт, а
  собирать их из сторонних источников — не то, что стоит делать.
  `.досье` показывает только профиль Telegram и поведение в переписке
  с вами.
* **Скачивания видео по ссылке** (TikTok, YouTube) — пока не сделано.
  Требует yt-dlp и ffmpeg, упирается в лимит Bot API на отправку и в
  блокировки серверных IP; делать вслепую смысла нет.

## Файлы

| Файл | Зачем |
|---|---|
| `main.py` | запуск, проверки, фоновая уборка, переживание лимитов |
| `admin.py` | админка: статистика, баннер меню, рассылка |
| `business.py` | разбор входящих: команда → мут → антискам → игра → автоответ |
| `handlers.py` | панель управления в личке |
| `engine.py` | решение «отвечать или молчать» — без Telegram и базы |
| `guard.py` | антискам: очки, признаки, объяснение |
| `whois.py` | оценка возраста аккаунта и поведения собеседника |
| `cmdbase.py` | каркас команд: разбор, права, подмена сообщения |
| `cmd_text.py`, `cmd_games.py`, `cmd_chat.py`, `cmd_profile.py`, `cmd_media.py` | сами команды |
| `styling.py`, `games.py`, `imaging.py` | чистая логика стилей, игр, картинок |
| `db.py` | SQLite со схемой и миграциями |
| `keyboards.py`, `texts.py` | кнопки и тексты |
| `selfcheck.py` | 48 проверок логики без сети: `python selfcheck.py` |

База лежит в `data/autochat.db` (или в `DATA_DIR`, если хостинг задаёт
свой том — иначе она сотрётся при первом передеплое). Схема при запуске
сама досыпает новые столбцы, так что обновление поверх работающего бота
данные не теряет.

Имя проекта — одна строка `BRAND` в `config.py`.

## Если не работает

* **«Этот бот пока не поддерживает режим секретаря»** — выключен
  Business Mode в @BotFather.
* **Подключился, но не отвечает** — в панели написано «без права
  отвечать»: включите разрешение в «Автоматизации чатов». Либо
  автоответы выключены, либо нет ни одного правила.
* **Команда остаётся в чате над результатом** — не выдано право
  «удалять мои сообщения».
* **Отвечает, когда не надо** — увеличьте паузу после вашего ответа или
  добавьте чат в исключения. Разобрать конкретный случай — `.почему`.
* **Антискам съел живого человека** — нажмите «это не спам» под
  карточкой, поднимите порог до 4–5.
* **Не видит удалённое** — сообщение пришло до подключения бота, вышел
  срок хранения архива или удалили ваше собственное.
