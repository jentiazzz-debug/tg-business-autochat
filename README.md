# autochat — автоответчик и «антиудаление» для Telegram Business

Бот подключается в **Настройки → Telegram для бизнеса → Автоматизация
чатов** и в личных чатах владельца делает две вещи:

1. **Отвечает от вашего имени** по правилам «слова → готовый ответ»,
   плюс режим «отошёл» и приветствие для новых собеседников.
2. **Показывает удалённое и изменённое.** Собеседник удалил фото, гифку
   или сообщение — бот присылает вам в личку карточку: кто, когда, что
   именно, и сам файл следом. Поправил текст — покажет «было → стало».

Управление целиком кнопками в личке бота, настройки у каждого владельца
свои.

## Что нужно

* **Telegram Premium** у владельца — без него раздела «Telegram для
  бизнеса» в настройках просто нет.
* **Business Mode у бота**: @BotFather → `/mybots` → ваш бот → *Bot
  Settings* → *Business Mode* → *Enable*. Пока он выключен, бота не
  будет видно в списке при подключении. Бот проверяет это при старте и
  пишет в лог.
* Python 3.10+.

## Установка

```bash
cd autochat
python -m venv .venv && .venv/Scripts/activate
pip install -r requirements.txt
cp .env.example .env        # впишите BOT_TOKEN и свой ALLOWED_IDS
python main.py
```

Затем в Telegram: **Настройки → Telegram для бизнеса → Автоматизация
чатов** → вставьте `@имя_бота` → выберите чаты. В личке бота появится
подтверждение и панель.

`ALLOWED_IDS` — ваш числовой id (можно несколько через запятую). Если
оставить пустым, подключить бота к своим чатам сможет любой, кто его
найдёт: у каждого будут свои правила и своя база, но работать он будет
на вашем сервере.

## Правила

Правило — это триггеры и ответ. Триггеры пишутся через `|`:

```
цена|сколько стоит|прайс   →   Прайс скину в течение часа.
```

* Совпадение ищется **с начала слова**: `цен` поймает «цена», «цену»,
  «ценник», но не «оценка». Для русского это заменяет морфологию.
* `=да` — точное совпадение целиком: сработает на «да» и не сработает
  на «да, конечно».
* Правила проверяются сверху вниз, отвечает первое подошедшее.
* В ответе работают подстановки `{name}`, `{username}`, `{time}`,
  `{date}`.

**Когда бот молчит** (разобрать конкретный случай — `/log`):

* вы сами написали в этот чат — пауза, по умолчанию 30 минут;
* только что уже отвечал в этом чате — пауза 2 минуты (ответ по
  *другому* правилу её обходит: на новый вопрос бот отвечает сразу);
* чат в списке исключений;
* ни одно правило не подошло, а приветствие и ответ по умолчанию
  выключены.

Из коробки правил нет и бот от вашего имени не пишет ничего — сначала
задайте, что отвечать.

## Удалённые сообщения: как это работает и чего ждать нельзя

Telegram присылает боту апдейт `deleted_business_messages`, в котором
**только номера сообщений** — ни текста, ни файлов. Поэтому бот
складывает входящие в свою базу в момент получения и достаёт их
оттуда, когда сообщение удаляют. Отсюда ограничения:

* видно только то, что пришло **после** подключения бота — истории у
  него нет;
* архив живёт ограниченный срок (по умолчанию 3 дня, меняется в панели);
* архивируются только **входящие**: свои сообщения бот не хранит и об
  их удалении не сообщает;
* файл переотправляется по `file_id`. Обычно он остаётся рабочим и
  после удаления, но самоуничтожающиеся фото так не достать — в этом
  случае придёт карточка с пометкой, что файл недоступен;
* всё это требует, чтобы боту в «Автоматизации чатов» не отключили
  право читать сообщения.

Ловится всё, что приходит сообщением: текст, фото, видео, GIF,
голосовые, кружки, файлы, стикеры, геолокации, контакты.

## Команды

| Команда | Что делает |
|---|---|
| `/menu` | панель управления |
| `/on`, `/off` | включить и выключить автоответы |
| `/away [текст]`, `/back` | режим «отошёл» и выход из него |
| `/rules`, `/add` | правила |
| `/stats`, `/log` | статистика и последние ответы |
| `/help` | справка |

## Файлы

| Файл | Зачем |
|---|---|
| `main.py` | запуск, проверки при старте, фоновая уборка |
| `business.py` | бизнес-апдейты: ответы, архив, удалённые, правки |
| `handlers.py` | панель управления в личке |
| `engine.py` | решение «отвечать или молчать» — без Telegram и базы |
| `db.py` | SQLite: подключения, настройки, правила, чаты, архив |
| `keyboards.py`, `texts.py` | кнопки и тексты |
| `selfcheck.py` | прогон логики ответов без сети: `python selfcheck.py` |

База лежит в `data/autochat.db` (или в `DATA_DIR`, если хостинг задаёт
свой том — иначе она сотрётся при первом же передеплое).

## Если не работает

* **Бота нет в списке при подключении** — выключен Business Mode в
  @BotFather.
* **Подключился, но не отвечает** — в панели написано «без права
  отвечать»: включите разрешение отвечать в «Автоматизации чатов».
  Либо автоответы выключены, либо нет ни одного правила.
* **Отвечает, когда не надо** — увеличьте паузу после вашего ответа
  или добавьте чат в исключения (раздел «Чаты»).
* **Не видит удалённые** — сообщение пришло до подключения бота, его
  удалили позже срока хранения, или удалили ваше собственное.
